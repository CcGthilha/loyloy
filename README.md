# ลอยด้วยกันนะ

เว็บลอยกระทงสองคน: สองสาวถือกระทงใบเดียวกัน คนหนึ่งฝากคำขอไว้ในลิงก์
อีกคนเปิดมาอ่าน พิมพ์คำขอของตัวเอง แล้วกดลอย

## ใช้ยังไง

1. เปิดหน้าแรก ใส่ชื่อกับคำขอของเรา กด "ทำลิงก์"
2. กด "ชวน" แล้วส่งลิงก์ให้เขา (ส่งลิงก์จากปุ่มนี้ ไม่ใช่จากแถบที่อยู่)
3. เขากดลอย ถ้าเราเปิดหน้ารอไว้ จะเห็นลอยพร้อมกันและได้คำขอเขา
   ถ้าไม่ได้เปิด เขากด "ส่งให้ดู" เพื่อส่งลิงก์ย้อนดูกลับมาได้

## รัน

    npm install
    npm run dev      # http://localhost:5180
    npm test
    npm run lint
    npm run build    # ได้ dist เอาขึ้นโฮสต์แบบ static

Netlify: เอาโฟลเดอร์ dist ขึ้นตรงๆ หรือถ้าต่อ git ใช้ build command `npm run build`, publish `dist`

## ข้อมูล

- คำขอเราอยู่หลัง # ในลิงก์ โฮสต์ไม่เห็น แต่ใครได้ลิงก์ก็อ่านได้
- คำขอเขาส่งตอนกดลอยเท่านั้น (ไม่ส่งระหว่างพิมพ์) เข้ารหัสผ่าน MQTT สาธารณะของ HiveMQ ไม่ได้เก็บไว้
- เว็บจำคำขอล่าสุดของเราใน localStorage ของเบราว์เซอร์เรา
