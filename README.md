# ลอยด้วยกันนะ

เว็บลอยกระทงสองคน: อ่านคำขอของเรา พิมพ์คำขอของเขา แล้วลอยกระทงใบเดียวกัน

- หน้าแรก: ส่งลิงก์นี้ให้เขาได้เลย
- หน้าลับเจ้าของ: ลิงก์ `#me.…` อยู่ในไฟล์ `my-link.local` (ไม่ขึ้น git อย่าส่งให้ใคร ทำหายอ่านคำขอไม่ได้)
- แก้คำขอของเราที่ `src/wish.js`

## รัน

    npm install
    npm run dev      # http://localhost:5180
    npm test
    npm run lint
    npm run build

## ข้อมูล

คำขอเขาถูกล็อกด้วยกุญแจสาธารณะตอนกดลอย แล้วฝากไว้ที่ MQTT สาธารณะของ HiveMQ ไม่เกิน 7 วัน
คนที่เปิดอ่านได้คือคนถือลิงก์ลับ ตัวกลางเป็นของฟรี ไม่รับประกันว่าไม่หาย
